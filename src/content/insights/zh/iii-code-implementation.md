自2016年1月1日起，**《IMO文书实施规则》（III规则）**已成为强制性规定。IMO成员国审核机制（IMSAS）下的审核，评估各国作为船旗国、港口国和沿海国履行义务的情况。

许多主管机关是在准备审核时才第一次接触该规则，这已经晚了。更有价值的做法，是把它作为一种设计工具，用来规划主管机关如何组织起来实施任何一项公约。

## 应尽早提出的三个问题

1. **每项义务是否都已落实到具体部门？** 每一项适用的文书都应有责任部门、法律依据以及处理修正案的程序。
2. **是否存在反馈闭环？** 记录、复核和纠正措施能够说明实施是否真正有效。
3. **委托职能能否得到有效监督？** 当认可组织代表国家行使职能时，监督必须真正到位，而不只停留在合同上。

## 务实的方法

对照该规则开展系统的差距评估，再制定按优先级排列、明确责任人和时间表的路线图，就能把审核准备转化为持久的机构能力提升。
